# Vinland

Минималистичная 2D Top-Down игра на MonoGame (.NET 10) с детерминированной многопоточной архитектурой.

> [!IMPORTANT]
> **Текущий статус**: Этап 1.5 (реализовано базовое перемещение игрока). Проект находится в активной разработке.

---

## ⚙️ Стек технологий

- **Ядро**: MonoGame + .NET 9
- **Физика**: Aether.Physics2D
- **Утилиты**: MonoGame.Extended (Tiled, Input, Particles, Cameras)
- **UI**: Myra
- **Логика**: Stateless (State Machine), Microsoft.Extensions.DependencyInjection
- **Данные**: LiteDB (NoSQL), System.Text.Json (конфиги сущностей)
- **Логирование**: Serilog (Async, File, Thread Enricher)
- **Тесты и бенчмарки**: xUnit, FluentAssertions, Moq, BenchmarkDotNet

---

## 🏗 Архитектура потоков

Проект использует строгое разделение ответственности с обменом данными через `System.Threading.Channels`.

| Поток | Ответственность | Синхронизация |
| :--- | :--- | :--- |
| **🟦 Main** | Рендер (`SpriteBatch`), UI (`Myra`), ввод, чтение очередей | Читает `Channel` в начале `Update()` |
| **🟨 Logic** | AI (`Stateless`), бой, спавн, детерминированный рандом | Фиксированный шаг (1/60). Пишет в `Channel` |
| **🟪 Physics** | `Aether.Physics2D.Step()`, коллизии, гравитация | Выделенный поток. Результаты позиций → `Channel` |
| **🟫 Data** | Сохранение (`LiteDB`), асинхронное логирование (`Serilog`) | Фоновые `Task` с `CancellationToken` |

---

## 📋 Этапы разработки

Текущий статус: **Фаза 0–1** (Фундамент, DI, базовая физика, передача данных через ChannelHub, портирование на Linux).

1. **Фаза 0**: Фундамент, ручной DI, `ChannelHub`, фиксированный шаг, Serilog.
2. **Фаза 1**: Карта (Tiled), игрок, физика (Aether), враги, UI (Myra).
3. **Фаза 2**: Активация многопоточности (Logic/Physics threads), детерминизм, бенчмарки.
4. **Фаза 3**: Управление комнатами, асинхронная загрузка, сохранения (LiteDB).
5. **Фаза 4**: Local Multiplayer (2-4 игрока, мультикамера, общий мир).
6. **Фаза 5**: Тестирование, профилирование, оптимизация и релиз.
